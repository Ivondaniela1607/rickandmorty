# Rick and Morty Characters App

Aplicación web desarrollada en **Angular** que muestra un listado de personajes de la serie **Rick and Morty**, utilizando la API pública [rickandmortyapi.com](https://rickandmortyapi.com/). Incluye filtros, detalles ampliados de cada personaje, episodios, localizaciones y residentes.

## 🛠️ Tecnologías utilizadas

- Angular
- RxJS (con `forkJoin`)
- TailwindCSS
- Angular Material (Paginator, Table)
- Signals (`@angular/signals`)
- Rick & Morty API (REST)
